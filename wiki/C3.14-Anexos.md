## D. Referencia rápida

### Tópicos del broker local

```
sabana/<nodo>/telemetria      nodo → gateway   QoS 0            cada 2 s
sabana/<nodo>/alerta          nodo → gateway   retenido         al cambiar
sabana/<nodo>/estado          nodo → gateway   retenido + LWT   online | offline
sabana/<nodo>/cmd/silenciar   gateway → nodo   QoS 1            "1" | "0"
sabana/<nodo>/ack             nodo → gateway   QoS 0
sabana/<nodo>/agregado        gateway → WLAN   retenido         cada 5 min
sabana/<nodo>/prediccion      gateway → WLAN   retenido         cada 30 min
sabana/gateway/estado         gateway → WLAN   retenido + LWT
```

### Ver lo que pasa, en la Raspberry

```bash
# Todo lo que circula por el broker
mosquitto_sub -h localhost -u monitor -P 'CLAVE' -t 'sabana/#' -v

# Últimos agregados
sqlite3 -header -column /var/lib/estacion/gateway.db \
  "SELECT datetime(ts_fin,'unixepoch','localtime') hora, n, perdidas, nivel_med, tasa_mmh, alerta
   FROM agregados ORDER BY id DESC LIMIT 12;"

# Lo que espera para salir a la nube
sqlite3 /var/lib/estacion/gateway.db "SELECT COUNT(*) FROM salida WHERE enviado=0;"

# Última predicción
sqlite3 -header -line /var/lib/estacion/gateway.db \
  "SELECT clasificacion, prioridad, tasa_mmh, exceso_mmh, horas_amarillo, recomendacion
   FROM predicciones ORDER BY id DESC LIMIT 1;"

# Bitácora del servicio
journalctl -u gateway-estacion -f
```

### Probar sin hardware

```bash
python3 simulador/simulador.py --escenario fuga --clave 'CLAVE_NODO' --ritmo 200
python3 pruebas/ejecutar_pruebas.py
```
